Interaction legend and test flow

  • Pointer: cyan marker when no button is pressed.
  • Primary button: red pointer marker and button dot.
  • Secondary button: magenta pointer marker and button dot.
  • Auxiliary button: green pointer marker and button dot.
  • Last click: yellow/orange ring. Repeated clicks alternate by clickSerial.
  • Active drag: cyan line/rectangle, green start marker, magenta current marker.
  • Completed drag: persistent line/rings. Repeated drags alternate by dragSerial.
  1. Move the pointer over the viewer.
  2. Hold left, right, or middle mouse buttons.
  3. Click repeatedly at the same position to verify clickSerial.
  4. Drag and release to verify drag start/current/end state.
  5. Toggle interaction forwarding off; shader-visible interaction state should clear.
  6. Toggle notifyOnMove to compare event-driven and polled readouts.
  7. Use capture mode none, drag, and all to compare viewer input behavior.
  8. Reorder the interaction-debug layer above or below other layers to test composition.
