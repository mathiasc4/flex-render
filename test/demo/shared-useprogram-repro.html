FlexRenderer shared-context useProgram repro

This harness tests the FlexRenderer build loaded by /build/openseadragon/flex-renderer.js. It uses one shared WebGL2 backing context and two separate presentation canvases. Viewer A is expected to render red and viewer B is expected to render green. The repro renders A, renders B, then renders A again through FlexRenderer's useProgram skip-load path. The old behavior leaves WebGL's context-global CURRENT_PROGRAM bound to B, so A incorrectly renders green; the fixed behavior rebinds A and the two viewers remain visually different.
